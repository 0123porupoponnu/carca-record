CARCA RECORD v1

ゆかり・げんじ専用のカルカソンヌ2人対戦記録アプリです。

使い方：
1. index.html を Safari/Chrome で開くと基本機能を使えます（端末・ブラウザによっては file:// の保存機能が制限されます）。
2. ホーム画面追加・オフライン利用を安定させるには、フォルダごと GitHub Pages 等の HTTPS ウェブサイトに配置してください。
3. データは利用端末のブラウザ内 IndexedDB に保存されます。自動クラウド同期はありません。
4. 設定 → バックアップ保存で写真付き JSON を保存してください。端末を変えた場合は JSON から復元できます。

機能：月・年集計、勝敗/勝率、先手・後手、同点は後手勝ち、写真最大3枚/試合、メモ、編集、削除、JSONバックアップ/復元。
